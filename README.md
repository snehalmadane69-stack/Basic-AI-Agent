# Basic AI Agent

## Objective
To build a simple rule-based AI agent that takes user input and makes a decision.

## Technology Used
- Python
- VS Code
- Python Virtual Environment

## How the Agent Works
1. The user enters a question or situation.
2. The agent converts the input into lowercase.
3. The agent checks predefined rules.
4. Based on the matching rule, the agent provides a response.

## Example

Input:
I have an exam tomorrow

Output:
You should make a study plan and start with important topics.

Input:
It is raining today

Output:
Take an umbrella and check the weather before going outside.

## Conclusion
The Basic AI Agent successfully accepts user input, applies predefined rules, and generates an appropriate response.
